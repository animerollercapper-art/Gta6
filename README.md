# Gta6
A fan made game

## Play the Game
Open `index.html` in a browser to play.

## Controls
- `Enter`: Start or restart
- Arrow keys: Move left, right, up, and down

## Notes
This repository now includes a small browser-based driving game built with HTML, CSS, and JavaScript.

## Unity Scripts
The `Assets/Scripts` folder contains cleaned Unity C# scripts for a simple game setup:
- `PlayerControllerCore.cs`
- `GameManager.cs`
- `UIManager.cs`
- `VehicleTrigger.cs`
- `MissionEngineCore.cs`
- `CombatSystemCore.cs`
- `Mission.cs`

To use them in Unity, create a scene with a player, UI text objects, and attach these scripts to the corresponding GameObjects.
